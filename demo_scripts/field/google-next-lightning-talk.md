## Act 1: The Hook (1 min)

> Show the end result before anything else. Pull up a pre-generated Imagen 3 product-in-scene visualization.

**Screen:** Wayfinder app with a completed product visualization — hiking boots composited into a mountain trail scene

- **Open:** "Let me show you where we're going to end up. This image was generated by an AI agent — it analyzed a photo of a hiking trail, recommended gear for that terrain, and then visualized one of those products in the scene. All of that was orchestrated by Elastic."
- **Bridge:** "Let me show you how we built this — starting from zero."

**Key beats:**
- The image is the hook — let it do the work
- Don't explain the tech yet, just the result
- Create curiosity: "how did it do that?"

## Act 2: Under the Hood — Agent Builder in Kibana (3 min)

> Switch to Kibana. Show Agent Builder UI with the trip-planner-agent.

**Screen:** Kibana → Agent Builder → trip-planner-agent

**2a. Agent Config (~1 min)**
- "This is Elastic's Agent Builder. No code — I'm configuring an AI agent right in Kibana."
- Show the system prompt — "it knows it's a trip planning assistant for an outdoor gear store"
- Show the model connector — point out which model is wired up
- "This agent can reason, but it needs tools to be useful."

**2b. Tools (~1 min)**
- Scroll to the tools list
- **product_search** — "This is an index search tool. It does semantic search over our product catalog. The embeddings use Jina's v5-text-small model — that's the default embedding model for Elasticsearch's `semantic_text` field type. State of the art embeddings, zero config."
- **ground_conditions** — "This is a workflow tool. It calls out to Gemini with Google Search grounding to get live weather and trail conditions. Not cached data — real-time."
- **check_trip_safety** — "Another workflow — safety assessment based on conditions"
- Don't linger on every tool — hit the highlights

**2c. Workflow Peek (~1 min)**
- Click into the ground_conditions workflow briefly
- "This workflow calls our backend, which uses Gemini 2.0 Flash with Google Search as a tool. The model can ground its response in real search results — so when it says 'trail conditions are icy,' that's from actual reports, not training data."
- **Key message:** "Declarative orchestration. No framework, no LangChain, no code to maintain. Agent Builder handles the routing."

**Audience Q&A buffer — this is a natural pause point if someone asks a question.**

## Act 3: The App in Action (4.5 min)

> Switch to the Wayfinder app (Cloud Run deployment). Trip Planner tab.

**Screen:** Wayfinder Supply Co → Trip Planner

### 3a. Text Query (~1 min)

- "Now let's use the agent we just looked at."
- Type: **"Planning a 3-day backpacking trip to Yosemite in April"**
- While streaming: "Watch the thought trace — you can see every tool call, every reasoning step. This is observable AI. The agent is checking weather, searching products, pulling in my preferences."
- Point out the streaming response and tool call indicators
- "It found gear rated for April conditions in Yosemite, not just generic 'hiking stuff.'"

### 3b. Image Upload — Jina VLM (1.5 min)

- "Here's where it gets interesting. What if instead of describing my trip, I just show the agent a photo?"
- **Click the image upload button. Upload a trail photo.**
- While Jina VLM processes: "The app sends this photo to Jina's Vision Language Model. It's analyzing the terrain — elevation, vegetation, trail conditions, season cues."
- When results appear: "Now look — the recommendations shifted. It saw rocky terrain and steep elevation in the photo, so it's recommending trekking poles, ankle-support boots, gear you'd actually need for this specific trail."
- **Key beat:** "The agent didn't just see 'a mountain.' It understood what kind of mountain and what gear that implies."

### 3c. Weather Grounding (~30 sec)

- Point to the weather/conditions card
- "This panel is Gemini with Google Search grounding. It's pulling live conditions — temperature, wind, trail status. This isn't hallucinated weather. The model searched Google for current Yosemite conditions."
- "The agent uses this to adjust its recommendations — if there's a storm warning, you'll see different gear."

### 3d. Product Visualization — Imagen 3 (1.5 min)

- "Now the wow moment."
- **Click "Visualize" on a recommended product** (pick something visual like boots or a jacket)
- While Imagen 3 generates (~10-30 sec): "Imagen 3 is generating this in real-time. It takes the terrain description from the Jina analysis and composites the product into that scene. Two-pass process — first it generates the environment, then it places the product."
- When the image appears: "That's your recommended hiking boot, on the trail you uploaded. This is the kind of experience that turns a product search into a product story."
- **Let the image land.** Don't rush past it — this is what you opened with.
